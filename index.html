The Alchemist is a novel written by Paulo Coelho, first published in 1988 in Portuguese and since then translated into more than 65 languages. The project is made upon an existing Wikipedia article which can be read by following this link https://en.wikipedia.org/wiki/The_Alchemist_(novel) which was encoded using the TEI Standard, therefore, every person, character, place, organisation, work, event and concept it mentions is marked in text and resolved against an authority list in the back matter, where entities are linked to Wikidata whenever an identifier exists.

From this encoding i devised two Python scripts to produce an annotated HTML version of the article and a machine-readable RDF dataset. Everything started with one simple question:

Research Question

Which kind of works and traditions inspired The Alchemist and how much it inspired other works? Across which media, countries and people?

Step I

Theoretical Model

After devising the research question, i created the theoretical model which describes the domain in natural language, before any formal vocabulary is chosen. The novel is sitting at the centre and every node is an entity taken from the article.

Step II

Conceptual Model

Starting from the theoretical model, i built the conceptual one, which abstracts it by replacing each entity and names with the class they belongs to, while each relation becomes a property taken from an existing vocabulary. In this case the model uses seven classes (creative works, persons, fictional characters, organisations, places, events and concepts) and reuses terms from Schema.org, Dublin Core, SKOS, DBpedia, MARC Relators, and the RELATIONSHIP vocabulary. New terms weren't coined because the existing vocabularies already covered the domain and reusing them keeps the data interoperable with other Linked Open Data sources.

Step III

Ontology Design

The conceptual model is formalised in an OWL ontology built with Protégé (https://w3id.org/alchemist/ontology). It works as an application profile: No new class or property has been coined, and every term is reused from an existing vocabulary. Each term is declared with its type and documented with an rdfs:comment explaining how it is used in the project.

Step IV

RDF Visualization

The Wikipedia article was encoded in XML following the TEI P5 Guidelines. The teiHeader records the metadata of the digital edition, while in the body every person, place, organisation, work and concept mentioned in the text is annotated with a dedicated element and linked, through @ref, to its entry in the back matter. There, each entity is described once and, whenever a record exists, reconciled with an external authority such as Wikidata, VIAF, WorldCat or the National Diet Library.

From the same TEI file, a Python script generates an annotated HTML version of the article, in which each type of entity is highlighted with its own colour. The XML stays the single source of the project as it is used to produce both this reading view and the RDF dataset.

The RDF dataset is generated automatically from the TEI file by a Python script with the help of lxml and rdflib libraries. It reads the entity lists of the back matter and translates each relation into a triple. Every entity has its own IRI in the project namespace and, where available, a link to Wikidata through rdfs:seeAlso.

Step V

As an extra, a second dataset describes the 13 works related to the novel as catalogue records: title, genre, year, creators and authority links. It is generated from a CSV file by a separate Python script and uses the same ontology and URIs, therefore it merges with the main dataset without conflicts.
