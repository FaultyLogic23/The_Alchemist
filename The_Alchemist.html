The Alchemist

The Alchemist is a project based on the book wrote by Paulo Coelho.

Why i have chosen this work?

This is the first book which actually brought "changes" in my life. The narrative, the writing and the symbolism used to create this "work" amazed me from the start but above all there is the "simplicity"

The project is made a-top an existing Wikipedia article which can be found by following this link https://en.wikipedia.org/wiki/Aaron_Swartz and the main goal is to create a machine-readable RDF dataset based on the encoding i made.

The first thing to do is to identify the entities in the Wikipedia article. I have identified [...] entities and used [...] categories, each one of them is reconciled to one external authority file which comes from Wikidata, VIAF, LCSH and Fabio.

Project made for the Information Science and Cultural Heritage Course
