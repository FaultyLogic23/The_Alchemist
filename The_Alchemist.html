The Alchemist is a project based on the book wrote by Paulo Coelho. It is made a-top an existing Wikipedia article which can be found by following this link https://en.wikipedia.org/wiki/The_Alchemist_(novel) and the main goal is to create a machine-readable RDF dataset based on the encoding i made.

Every person, place, organization, work and concept mentioned in the article is marked in TEI and resolved against a back-matter authority list, where each entity carries a Wikidata identifier.

The conceptual model groups the article's entities into five categories and shows how each of them relates to the novel.

The theoretical model translates the same picture into the vocabulary of TEI and RDF: each category becomes a class, each relation a typed property and the whole graph is expressed in terms that a machine can read and query.
